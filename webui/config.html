Master switch. When ON, the caveman style is injected into every agent turn whose chat has caveman switched on. A chat can still opt out with /caveman off or the topbar selector.
Default for chats with no override. Each chat can override this with the topbar selector or /caveman <level>.
Recommended. Tells the model to drop caveman style for security warnings, irreversible operations, and ambiguous multi-step sequences, then resume.
Swap the base style for a compact variant (~350 tokens injected per turn instead of ~800; the level's own rules are unchanged). Cheaper on short workloads. Measured with benchmarks/run.py --lean.
Compress tool names and descriptions before each model call. Off by default: tool descriptions are the contract the model reads when it calls a tool, and over-eager compression can change what a tool appears to do. Only enable this if you have measured the effect on your own tool set.
Delete banned filler phrases from the model's own output at the ultra and wenyan-* levels. Off by default: this is phrase deletion, not rewriting, so removing an opener such as "Sure!" can leave a sentence fragment behind. Every strip is logged as a warning. Does nothing at lite and full.
